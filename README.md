# CosmoCare AI
Real-time astronaut health monitoring dashboard with anomaly detection and alerts.
NASA Space Apps Challenge 2026: Create Health Monitoring Software for Astronauts on Space Missions.

## Folders
- backend/  : FastAPI API (Huzaifa)
- ml/       : data + anomaly detection (Data/ML teammate)
- frontend/ : Next.js dashboard (Frontend teammate)
- docs/     : slides, script, screenshots (Design teammate)

Note: vitals data is simulated unless stated otherwise.
